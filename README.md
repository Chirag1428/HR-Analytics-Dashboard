# HR-Analytics-Dashboard

The HR Analytics Dashboard provides valuable insights into employee data, such as attrition rates, demographics, departmental performance, and satisfaction levels. This dashboard helps HR managers and leadership understand workforce trends and take proactive actions to improve employee retention and efficiency.

Dashboard Insights :

1. Employee Overview – Headcount, gender ratio, and department distribution

2. Attrition Analysis – Attrition rate by department, age, and tenure

3. Performance & Satisfaction – Visuals showing job satisfaction, performance rating, and income trends

4. Tenure Breakdown – Analysis of years at company, years in current role

5. Drill-through View – Deep dive into individual employee details (optional)
